## User Stories

### Daniel
* User Stories
1. Als speler wil ik de speciale wijnflessen uit de bedroom en storage room kunnen oppakken en aan mijn inventory toevoegen<br>
2. Als speler wil ik de wijnflessen in mijn inventory kunnen bekijken om de tweede puzzel van de storage room op te kunnen lossen<br>
3. Als speler wil ik de kist in de storage room kunnen openen met de samengestelde code van de wijnflessen.<br>
4. Als speler wil ik het voorwerp in de storage room kist met daarop de deelsleutel voor de endroom kunnen oppakken.<br>
