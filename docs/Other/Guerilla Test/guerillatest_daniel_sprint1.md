# Gebruikerstest

**1. Doel van de Test**  
Ik heb een room gemaakt en zou graag willen weten of mensen het design makkelijk vinden om te gebruiken en niet ergens vastlopen.
<br/>

**2. Testmethode**  
Er is getest aan de hand van de Guerilla methode.
<br/>

**3. Testmateriaal**
De game
<br/>

**4. Doelgroep**  
Een willekeurige HBO-ICT student
<br/>

**5. Testprocedure**

-   Zoek een drukke plek met veel mensen
-   Vraag of mensen willen deelnemen aan onze korte guerilla test
-   Geef ze een simpele opdracht en noteer hoe lang dit duurt en dus hoe makkelijk dingen te vinden zijn.
-   Stel specifieke vragen over layout, navigatie, en gebruiksgemak.
-   Noteer alle feedback, suggesties, en observaties
    <br/>

**6. Meetbare Criteria**

-   Begrijpelijkheid van de interface.
-   Intuïtie van de navigatie.
-   Eventuele verbeterpunten of problemen die gebruikers als feedback geven.  
    <br/>

**7. Feedback Verwerking**

-   Verzamel en analyseer alle feedback
-   Bespreek de resultaten met je team en hoe we dit kunnen verwerken
-   Pas de designs aan op basis van de verzamelde feedback  
    <br/>

**8. Documentatie**
Alle verzamelde feedback is gedocumenteerd zodat ik er altijd ernaar terug kunnen kijken.  
<br/>

## Sprint 1

Ik heb de gebruiker een laptop gegeven waar de game op draait. De gebruiker heb ik verteld dat hij een object moesten bekijken en iets moesten openen. Ik heb de tijd geregistreerd. Daarna heb ik gevraagd wat hij er van vond en hoe tevreden hij was door een cijfer te geven van 1-10.
<br/>

### Resultaten van de tests

#### Wat waren de 2 doelen?

Gebruikersdoel: Vind de wijnflessen.<br>  
Als game developer wil ik dat de 'verborgen' wijnflessen gevonden worden.

Gebruikersdoel: Observeer de wijnflessen voor hints.<br>  
Als game developer wil ik dat de gevonden wijnflessen geinspecteerd worden door de gebruiker zodat de padlock-code ontcijferd kan worden a.d.h.v. de jaartallen op de flessen.

#### Tester - Berkay

**Resultaattabel:**

| #   | Doel/User Story                        | Effectiviteit | Efficientie | Tevredenheid |
| --- | -------------------------------------- | ------------- | ----------- | ------------ |
|     | Wat moet je gebruiker kunnen bereiken? | Doel behaald? | Tijd        | /10          |
| 1   | Vind de wijnflessen                    | Ja            | 20sec       | 8/10         |
| 2   | Observeer de wijnflessen voor hints    | Ja            | 5sec        | 8/10         |

**Observaties van de tester:**

-   Het was vrij duidelijk
-   Ik las dat het om een wine cellar ging dus het leek mij logisch dat ik daar de flessen zou vinden.

**Algemene feedback:**

-   Er is nog weinig inhoud
-   Multiple choice keuze geven voor de code voor de chest
-   Chest mag nog leeg zijn

<br/>

### Nieuwe user stories

Op basis van bovenstaande feedback heb ik deze user story aangepast: <b>Als speler wil ik de kist in de storage room kunnen openen met de samengestelde code van de wijnflessen.</b> Het 2e punt over multiple choice keuze voor het invoeren van de code heb ik hierin verwerkt.
